# Magia Exedra セリフ検索

『魔法少女まどか☆マギカ Magia Exedra』関連ストーリーのセリフを、キャラクター名や本文から検索できる単体HTMLツールです。

## 主な機能

- キャラクター名による検索
- 日本語・英語セリフのキーワード検索
- キャラクター名とセリフの組み合わせ検索
- キャラ別セリフ数ランキングTop20
- 全順位のTXT出力
- 名前が曖昧な場合の1文字ワイルドカード検索
- ブラウザ内への取得データ保存（IndexedDB）
- Puella Magi Wikiからのデータ更新

## 使い方

1. `Magia_Exedra_セリフ検索.html` をブラウザで開きます。
2. 初回はPuella Magi Wikiからデータを取得するため、インターネット接続が必要です。
3. 2回目以降は、ブラウザに保存された取得済みデータを利用できます。
4. 最新状態へ更新したい場合は「Wikiから更新」を押します。

サーバーやビルド環境は不要で、HTMLファイル単体で動作します。

## データ取得元

データはPuella Magi Wikiの以下のページと、そのページからリンクされているストーリー書き起こしページから取得します。

- [Magia Exedra Story Transcripts](https://wiki.puella-magi.net/Magia_Exedra_Story_Transcripts)

本リポジトリにセリフデータそのものを同梱しているわけではありません。HTMLを実行したブラウザが、利用者の操作によりWikiから取得してブラウザ内へ保存します。

## 現在の対象範囲

このツールが取得できる範囲は、上記インデックスページからリンクされている書き起こしページに依存します。

- マギアレコード第1部など、現在インデックスに掲載されているストーリーが対象です。
- **マギアレコード第2部は現在の対象に含まれていません。**
- **Scene 0は現在の対象に含まれていません。**
- Wiki側で未収録・未翻訳・リンクされていないページは検索できません。
- Wikiの更新や表記変更によって、件数や検索結果が変わる場合があります。

## セリフ数の数え方

- 通常の会話行を1件として数えます。
- キャラクター名が付いた内心・回想・ナレーションは、そのキャラクターの1件として数えます。
- 話者名のない地の文・効果音・ナレーションはキャラクターランキングから除外します。
- 日本語名が同じで英語名だけが異なる表記揺れは、同一キャラクターとして統合します。
- `小さなキュゥべえ` と `小さいキュゥべえ` は同一キャラクターとして統合します。
- 通常の `キュゥべえ` と `小さなキュゥべえ` は別キャラクターとして扱います。
